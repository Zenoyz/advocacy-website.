\# Proyecto Final - Playas Limpias Puerto Rico



Este repositorio será usado para mi proyecto final de la clase de Desarrollo Web.



\## Tema

El tema escogido es \*\*mantener limpias las playas de Puerto Rico\*\*.



\## Idea

La página web será de advocacy. El objetivo será informar sobre el problema de la basura en las playas y motivar a las personas a colaborar para cuidarlas.
